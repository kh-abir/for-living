# PRANGON — Brand Logo Guidelines

## The Mark: Chisel Block

A solid block with the letter **P** carved in negative space. The block represents raw material and architectural mass; the carved P represents craft mastery and precise execution.

**Concept:** *Raw material meets mastery — the architecture of craft made visible.*

## Clear Space & Minimum Size

- **Clear space:** Minimum distance = width of P's stem (40 units at 256 = ~15.6% of mark height). No elements may intrude into this zone.
- **Minimum size — digital:** 24px height (P remains readable)
- **Minimum size — print:** 8mm height
- **Favicon/app icon:** Use exported favicon variants which have optimized sizing

---

## Logo Misuse

Do not:
- ❌ Rotate or skew the mark
- ❌ Add shadows, gradients, or glow effects to the symbol
- ❌ Change the corner radius of the block
- ❌ Alter the P proportions
- ❌ Place on busy photo backgrounds without sufficient contrast overlay
- ❌ Outline the block (it must remain filled)
- ❌ Use colours outside the approved palette for the block fill
- ❌ Stack or tile multiple marks

---

## Approved Block Fill Colours

Only these colours may be used for the block background:
1. `#12100e` (Espresso/Dark) — default
2. `#bd7b58` (Terracotta) — warm variant
3. `#000000` (Pure black) — one-colour printing
4. `#ffffff` block, `#12100e` P — reversed variant

The carved P always uses `#f8f9ee` (Bone) on dark blocks, or `#12100e` on white/light blocks.

## Web Integration

Add to `<head>`:
```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#12100e">
```

Copy favicon files from `brand/logo/final/` to `public/`:
- `favicon.ico`, `favicon.svg`
- `apple-touch-icon.png`
- `icon-192.png`, `icon-512.png`, `maskable-512.png`
- `site.webmanifest`
